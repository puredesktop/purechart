# PureChart Design

PureChart turns CSV, JSON, or pasted tables into beautiful, exportable charts.

The product should make data import, chart selection, encoding, styling, inspection, and export feel direct. Parsing, chart specifications, layout, theme, interactions, exports, paths, and agent chart tools are app-owned domain concerns.

The assistant contract should help users inspect chart context, load or create chart specs, adjust titles, chart types, encodings, style, data, and export settings while preserving the user's control over the final visual output.
